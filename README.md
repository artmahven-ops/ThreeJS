# ThreeJS
Three.js is a JavaScript library that makes it easy to create and display 3D graphics directly in web browsers using WebGL, without needing complex low-level code. It handles scenes, cameras, lights, materials, and animations, allowing developers to build interactive 3D games, product previews, and immersive websites.

## How To Use?

**Termux:**
- pkg update && pkg install git nodejs
- git clone https://github.com/artmahven-ops/ThreeJS.git
- cd ThreeJS
- npm install (jika ada file package.json)
- node index.js

**Windows (PowerShell/CMD):**
- winget install --id Git.Git -e --source winget
  *(Atau menggunakan Chocolatey: `choco install git`)*
- git clone https://github.com/artmahven-ops/ThreeJS.git
- cd ThreeJS
- node index.js

**Linux (Ubuntu/Debian):**
- sudo apt update && sudo apt install git nodejs npm -y
- git clone https://github.com/artmahven-ops/ThreeJS.git
- cd ThreeJS
- node index.js
